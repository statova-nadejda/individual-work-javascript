### Настройка проекта 

Rock Legends — это веб-приложение, позволяющее пользователям просматривать список рок-групп, открывать страницы конкретных групп с подробной информацией и добавлять, удалять любимые треки в избранное. Каждая группа открывается по шаблону с подставкой данных через параметр id.

### Шаг 1. Создание структуры данных `bands.json` 

Файл bands.json содержит массив объектов, каждый из которых описывает одну музыкальную группу. Эти данные используются для генерации содержимого страниц.

Каждый объект содержит следующие поля: 

- `id` - Уникальный идентификатор группы
- `name` - 	Название группы
- `years` - Годы активности
- `history` - Подробная история и биография группы
- `songs` - Массив названий популярных песен группы
- `image` - Относительный путь к изображению группы

### Шаг 2. Класс `Band.js`

Класс Band представляет одну музыкальную группу и инкапсулирует логику генерации HTML-карточки этой группы для отображения на странице.

```
constructor({ id, name, years, history, image, tracks })

```
Конструктор присваивает объекту группы необходимые свойства.Это позволяет удобно работать с группой как с объектом, особенно при отображении данных на разных страницах.

Метод `createCard()` Создаёт DOM-элемент div с классом band-card. Внутри карточки отображаются:
- Изображение (<img>)
- Название группы (<h3>)
- Кнопка "Learn more" (внутри `div.button-wrapper`)

ДобавляеМ обработчик события клика на карточку группы `card`. Когда пользователь кликает по карточке, происходит переход на страницу с подробной информацией о группе.

Этот метод вызывается для каждой группы, загруженной из bands.json, чтобы отобразить её карточку на странице bands.html: 

```
createCard() {
    const card = document.createElement('div');
    card.className = 'band-card';
    card.innerHTML = `
      <img src="${this.image}" alt="${this.name}">
      <div class="band-content">
        <h3>${this.name}</h3>
        <div class="button-wrapper">
          <button type="button" class="learn-more-button">Learn more</button>
        </div>
      </div>
    `;}
```

### Шаг 3. Страница со списком всех групп. 

Файл `allBands.js` подключён на странице bands.html.

`allBands.js` отвечает за отображение всех музыкальных групп на отдельной вкладке сайта. Его задача — динамически сформировать карточки с краткой информацией о группах на основе данных, полученных из внешнего JSON-файла.

- Импортируется класс Band из внешнего модуля Band.js. Этот класс инкапсулирует логику создания карточек групп.

- Одним из ключевых аспектов реализации этого файла является асинхронная загрузка данных из `bands.json`. Для этого используется функция `fetch`, возвращающая промис.С ее помощью загружается файл `bands.json`, содержащий массив объектов с данными о музыкальных группах (название, изображение, годы активности, список песен и т.д.).

```
fetch('./../bands.json')
  .then(res => res.json())
  .then(bandsData => {
    const container = document.getElementById('bands-container');
    bandsData.forEach(bandObj => {
      const band = new Band(bandObj); 
      container.appendChild(band.createCard()); 
    });
  });

```

После получения и преобразования JSON-ответа в JavaScript-объекты для каждой группы создаётся экземпляр класса `Band`, вызывается метод `createCard()`, который формирует DOM-элемент карточки. Эти карточки поочередно добавляются в HTML-элемент с идентификатором `bands-container`.

### Шаг 4. Страница каждой отдельной группы.

Скрипт bandPage.js подключён к странице band.html.

Файл отвечает за отображение подробной информации о музыкальной группе, выбранной пользователем. Данные берутся из JSON-файла, идентификатор группы извлекается из URL, и на его основе подставляется нужная информация.

```
document.addEventListener("DOMContentLoaded", async () => {
  const params = new URLSearchParams(window.location.search);
  const id = params.get("id");
  ...

```

С помощью URLSearchParams получаем параметр id из строки запроса, после того, как полностью загрузится HTML-структура страницы (используется событие `DOMContentLoaded`)

Далее через `fetch` загружается `JSON-файл` `bands.json`. С помощью `.json()` ответ парсится в массив объектов. Выполняется поиск объекта группы по совпадению `id`. Если он не найден - выводится сообщение об ошибке. В противном случае, обновляются элементы с информацией о названии, изображении, годах активности и истории.

```
document.getElementById("band-name").textContent = band.name;
    document.getElementById("band-image").src = band.image;
    document.getElementById("band-image").alt = band.name;
    document.getElementById("band-years").textContent = `Годы активности: ${band.years}`;
    document.getElementById("band-history").textContent = band.history;
```

Для каждого трека группы создается элемент <li>, содержащий название и кнопку "Добавить в избранное". При нажатии на кнопку трек добавляется в localStorage под ключом favoriteSongs. также повторное добавление одного и того же трека предотвращается.

```
const button = document.createElement("button");
button.className = "add-favorites-button";
button.textContent = "Добавить в избранное";

```
